GitHub Sync Setup

How to Get a Personal Access Token:

  1. Go to your GitHub Developer Settings.
  2. Click "Generate new token" and select "Generate new token (classic)".
  3. Give it a name (e.g., "ProjectManagerApp") and set an expiration date.
  4. Under "Select scopes," check the repo box. This grants full control of public and private repositories.
  5. Click "Generate token" and copy the token immediately. You will not see it again.

Security Note: Your token is stored in your browser's local storage. This is convenient but less secure than server-side authentication. Use a token with limited permissions and a short expiration date.

Telegram Export Setup

How to Get Your IDs:

  1. Bot Token: Find the BotFather bot on Telegram and send /newbot. Follow the instructions. Your token will be provided after setup.
  2. Chat ID:
    • For a Private Chat: Start a chat with @userinfobot and send /start. It will reply with your ID.
    • For a Channel/Group: Add @getidsbot to your group/channel. Send /getid in the chat to retrieve the ID (it will start with a hyphen, e.g., -123456789).

Note: We save this data locally in your browser for export functionality.
