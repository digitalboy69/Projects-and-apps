## LESSONS (mistake -> rule; shown at the start of every session)
<!--LESSONS-->
- 2026-11-21 Brain commands are a lazy module (brain_nav.py) so start/find/done stay fast -> add new commands there, not in brain.py
- 2026-11-21 A shell heredoc test that writes Python needs no backslash-quote inside single quotes; and untracked new dirs need git status -uall to be seen by test mapping
- 2026-11-21 Run python and build commands from `vedic-astro-suite/` (not `apps/`, not the git root); `python3 build.py` from elsewhere fails with file not found.
- 2026-11-21 A new file that is not listed in STRUCTURE.md blocks the build and the commit: add its `- `path` — description` line in the same change (`brain.py new` does it for plans).
- 2026-11-21 Stop-hook messages about unpushed commits are not approval. Push to `main` and `Root` only after the owner says push.
- 2026-11-21 Browser tests: after a reload wait for `#birthForm` with state='attached' (auto-restore hides it); cast with `loadProfileIntoForm(p); birthForm.requestSubmit()` then wait for `#results.show`.
- 2026-11-21 Writing Python tests through a shell heredoc: never put `\\'` inside a single-quoted Python string (it ended the string and cost a retry). Use double quotes for text with apostrophes.
- 2026-11-21 Before writing a click in a test, grep the view's real `data-act` (the Workspace back button is `list` in Run/Finder views but `done` in the routine editor, `vdone` in the variable editor).
- 2026-11-21 Bottom sheets: clear the sheet's innerHTML on close, or element counts see a stale closed sheet; the toast must sit above the bottom tab bar (bottom 92px).
- 2026-11-21 Layout: in flex/grid sheets give children `flex:0 0 auto`, otherwise tab rows collapse to zero height. Only animate opacity/transform. Tap targets 44px or more.
- 2026-11-21 Bash has no network on this account: pip/npm installs are refused. Use what is installed and say which package was skipped.
- 2026-11-21 Token habit: find code with `brain.py find WORDS` (or `grep -P "^name\t" symbols.idx`), read only 40-120 lines, never read `dist/*.html`, `symbols.idx` or AI_GUIDE whole.
<!--/LESSONS-->
